# Plataforma Web para la Experimentación con Modelos de Análisis de Sentimientos 🎭📊

Este proyecto es parte del Trabajo Final del **Máster en Inteligencia Artificial** de Josué García Asensi, defendido en julio de 2025 bajo la dirección de **Ane Iturzaeta Agirre**.

## 🧠 Descripción

Esta plataforma web interactiva permite a los usuarios experimentar con distintos modelos de inteligencia artificial para el **análisis de sentimiento** en reseñas de películas. Está especialmente diseñada con fines educativos, facilitando la exploración de modelos de Procesamiento de Lenguaje Natural (NLP).

Los usuarios pueden comparar resultados, observar cómo responden los modelos a entradas similares y profundizar en las capacidades actuales del PLN.

## 🌐 Tecnologías Utilizadas

- **Frontend Framework**: [Vue.js](https://vuejs.org/)
- **Empaquetador**: [Vite](https://vitejs.dev/)
- **Estilo**: Tailwind CSS
- **HuggingFace Inference API**

## 🚀 Características Principales

- ⚡ Interfaz simple e intuitiva
- 🔁 Comparación entre múltiples modelos NLP
- 📊 Resultados visuales y análisis comparativo
- 🧪 Experimentación directa con ejemplos personalizados
- 📚 Objetivo educativo y fácilmente ampliable
